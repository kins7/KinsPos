# KinsPOS Downloads

Download the latest installer or standalone package from [Releases](https://github.com/kins7/KinsPos/releases/latest).

- **KinsPOS_Setup.exe**: Recommended Windows installer.
- **KinsPOS_Standalone.zip**: Extract the entire ZIP, then open `KinsPOS/KinsPOS.exe`. Keep all extracted files together.
- **SHA256SUMS.txt**: SHA-256 checksums for both downloads.

A license must be supplied by your software provider or administrator.

This repository hosts downloads only. Application source code is not published here.
